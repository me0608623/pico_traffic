2️⃣ 打包方案
========================================

方案 A：最小包（推薦給測試）
----------------------------
包含：index.html + tesla_cybertruck.glb + README.md

Windows：
  1. 選擇這三個文件
  2. 右鍵 → 傳送到 → 壓縮的資料夾
  3. 命名為：pico_traffic_mini.zip

  zip -r pico_traffic_mini.zip index.html tesla_cybertruck.glb README.md

方案 B：完整包（推薦給正式使用）
----------------------------
包含：所有 .html、.glb 和文檔文件

Windows：
  1. 選擇整個 pico_traffic 資料夾
  2. 右鍵 → 傳送到 → 壓縮的資料夾
  3. 命名為：pico_traffic_full.zip

Linux/Mac：
  cd ..
  zip -r pico_traffic_full.zip pico_traffic/ \
    -x "pico_traffic/.git/*" \
    -x "pico_traffic/node_modules/*" \
    -x "pico_traffic/__pycache__/*"

方案 C：Git 倉庫（推薦給開發者）
----------------------------
直接克隆倉庫：
  git clone git@github.com:me0608623/pico_traffic.git

或下載 ZIP：
  https://github.com/me0608623/pico_traffic/archive/refs/heads/final.zip

3️⃣ 本地運行方式
========================================

前置需求：
  - 選項 A：Python 3（最常見）
  - 選項 B：Node.js（前端開發者）
  - 選項 C：PHP（後端開發者）

方法 1：使用 Python（推薦）
----------------------------
步驟：
  1. 打開終端機/命令提示字元
  2. cd pico_traffic
  3. python3 -m http.server 8000
  4. 打開瀏覽器：http://localhost:8000/index.html

停止：按 Ctrl+C

方法 2：使用 Node.js
----------------------------
步驟：
  1. cd pico_traffic
  2. npx http-server -p 8000
  3. 打開瀏覽器：http://localhost:8000/index.html

停止：按 Ctrl+C

方法 3：使用 PHP
----------------------------
步驟：
  1. cd pico_traffic
  2. php -S localhost:8000
  3. 打開瀏覽器：http://localhost:8000/index.html

停止：按 Ctrl+C

方法 4：直接打開（不推薦）
----------------------------
  直接雙擊 index.html
  
  ⚠️ 注意：
  - 可能因為跨域問題無法載入模型
  - 建議使用上述方法啟動本地伺服器

4️⃣ 分享給他人
========================================

情境 A：同一網路（區域網路）
----------------------------
1. 啟動伺服器（允許外部訪問）：
   
   Python：
   python3 -m http.server 8000 --bind 0.0.0.0
   
   Node.js：
   npx http-server -p 8000 -a 0.0.0.0

2. 查找您的 IP：
   
   Windows：
   ipconfig
   
   Linux/Mac：
   hostname -I
   或
   ifconfig | grep "inet "

3. 分享網址給他人：
   http://您的IP:8000/index.html
   例如：http://192.168.1.100:8000/index.html

4. 他人在同一 WiFi 下，用瀏覽器訪問即可

情境 B：不同網路（網際網路）
----------------------------
使用隧道服務：

選項 1 - localtunnel（最簡單）：
  npx localtunnel --port 8000
  會得到公開網址：https://random-name.loca.lt

選項 2 - ngrok（最穩定）：
  ngrok http 8000
  會得到公開網址：https://random-id.ngrok.io

選項 3 - serveo（只需 SSH）：
  ssh -R 80:localhost:8000 serveo.net
  會得到公開網址：https://abc.serveo.net

情境 C：永久分享（GitHub Pages）
----------------------------
已部署：https://me0608623.github.io/pico_traffic/

直接分享此網址！

情境 D：壓縮文件分享
----------------------------
1. 打包文件（見「方案 A」或「方案 B」）
2. 上傳到雲端硬碟：
   - Google Drive
   - Dropbox
   - OneDrive
   - WeTransfer
3. 分享下載連結
4. 對方下載後解壓縮，按「本地運行方式」啟動

6️⃣ 常見問題
========================================

Q1：模型無法載入，顯示灰色方塊？
A1：
  ✅ 確認使用本地伺服器（不要直接打開 HTML）
  ✅ 確認 tesla_cybertruck.glb 文件完整
  ✅ 檢查瀏覽器控制台（F12）錯誤訊息
  ✅ 確認網路連接（需載入 Three.js CDN）

Q2：其他人無法訪問我的本地伺服器？
A2：
  ✅ 確認使用 --bind 0.0.0.0 或 -a 0.0.0.0
  ✅ 檢查防火牆設定
  ✅ 確認兩台電腦在同一網路
  ✅ 嘗試 ping 測試連接

Q3：GitHub Pages 顯示 404？
A3：
  ✅ 等待 2-3 分鐘讓部署完成
  ✅ 檢查 Actions 頁面是否有錯誤
  ✅ 確認 Settings → Pages 已啟用
  ✅ 確認分支設定正確

Q4：壓縮文件太大無法分享？
A4：
  ✅ 只打包最小包（~60MB）
  ✅ 使用雲端硬碟分享
  ✅ 使用 WeTransfer（支持大文件）
  ✅ 或直接分享 GitHub 倉庫

Q5：車輛重疊或行為異常？
A5：
  ✅ 點擊「重置所有車輛」
  ✅ 重新整理頁面（F5）
  ✅ 強制刷新緩存（Ctrl+Shift+R）

Q6：網站顯示舊版本？
A6：
  ✅ 強制刷新：Ctrl+Shift+R
  ✅ 清除瀏覽器緩存
  ✅ 等待 2-3 分鐘讓 CDN 更新
  ✅ 嘗試無痕模式

Q7：沒有安裝 Python/Node.js 怎麼辦？
A7：
  ✅ Python：https://www.python.org/downloads/
  ✅ Node.js：https://nodejs.org/
  ✅ 或直接訪問線上版：
     https://me0608623.github.io/pico_traffic/

Q8：檔案大小警告？
A8：
  tesla_cybertruck.glb (60MB) 超過 GitHub 建議的 50MB
  但仍可正常使用，不影響功能！
